## Scope treatment

Task 1 is the tracer: the helper, the local pass's use of it and the fixture's dangling link land together, so the first commit already proves that a dangling symlink is counted, not named, end to end through title.local.fixture. Task 2 adds the bad-name faults, the bad directory name, the absolute OUT and the marker-guarded scratch tree with their fixture runs. Task 3 moves library.cmake onto the same rule, proves the rule's `library` pass and fault paths inside title.local.fixture (so `cmake --workflow --preset ci` exercises every behaviour this plan adds to library.cmake's shared rule, per rules 5 and 7), and updates the user doc. The two configure-time call sites in library.cmake run on the library CI job's pass path on every heavy change. Their fault direction is held by a source check in title.local.fixture (route chosen for the iteration-2 warning, the cheaper of the two offered): it reads library.cmake and fails when a configure-time scan bypasses compat_files or compat_name_check, and it is proven on three fault copies inside the same test, so a revert of library.cmake turns every ci lane red. Configuring the library preset inside a ci test was rejected: it needs build/ci/built and the OpenBIOS image, registers the whole library test set and would cost far more than a text check. The one-shot configure fault checks in Task 3 add to that and are not the recurring coverage. Choices made under discretion: every symlink is counted as unread rather than followed, as the verification asks, so the pass reads only the files the named directory itself holds (reversible, one condition in the helper); the fixture drives the shared rule through a -P entry in files.cmake rather than a script generated under WORK, because a generated script under WORK would put the WORK path into CMake's own call-stack text on a fault and so trip the fixture's no-path check; the scratch tree is guarded by a marker file rather than by refusing every existing `<OUT>.rows`, so a re-run of the library preset still replaces its own tree.
