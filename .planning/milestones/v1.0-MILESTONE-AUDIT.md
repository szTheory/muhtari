## End-to-end flows

1. No-content core → palette/PNG → runner hash and actual RetroArch image.
2. Built cartridge → validated load → fast or OpenBIOS handoff → title predicate.
3. Input movie → VBLANK latch → changed gameplay image and audible completed PCM;
   no-input, wrong-port, static/late/mirror and muted controls reject incorrect results.
4. Declared TIA/POKEY → public frame PCM → raw/PCM runner hashes → all-platform equality.
5. Actual libretro module → batch and single-sample callbacks → sample equality,
   including missing callbacks, reset and reload; rcheevos consumes real memory descriptors.
6. Phase merge → App release PR → green CI → attested package publication → latest install.
