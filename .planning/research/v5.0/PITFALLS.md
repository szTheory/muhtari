# Pitfalls — v5.0

| Failure | Required prevention |
|---|---|
| Loader paired with another source's Wasm | Same-source identity and extracted-pair controls; retain tag/source binding throughout the release join. |
| Tests pass against build files while archive is broken | Execute the existing consumer from a clean extraction with no fallback to original artifacts. |
| Extra fixtures, state or firmware leak | Exact member/path contract and existing prohibited-content scanning; ship no diagnostic input, observer output or measurement receipt. |
| New archive bypasses native publisher security | Extend exact archive names, checksums, attestations, tamper/download checks and rehearsal selection together; keep native behavior. |
| Generated runtime distributed without obligations | Inspect exact pinned permissively licensed inputs, record provenance and include required notices before distributing. |
| Duplicate full CI for one package | Reuse the existing Emscripten producer and existing native expectations; add only recurring package-regression checks. |
| Headless proof inflated into browser acceptance | Document Node/core evidence and real-browser/device unknowns separately. |
| Prior host denial silently retried | Preserve exact Phase 12/14 stops, unmerged source and nine deferred requirements. |
| Optimization chosen from censored or mixed-attempt data | Record source/attempt and keep current deadlines/advisory distinctions; no cache/topology change without measured evidence. |

Publication and public rehearsal are remote actions. Local implementation does not authorize them. Existing hooks and the project's finite review/gap rounds remain binding.
