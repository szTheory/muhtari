# Features — v5.0

## Recommended outcome

A host integrator obtains the matching Emscripten loader and WebAssembly core as a version-free, checksummed libretro release archive instead of building it or retrieving a CI artifact. Prepare and verify this distribution locally; actual public rehearsal, publication and merge retain their separate ship boundary.

## Scope

- Mandatory SEED-007 tune-up: reconcile current publication/docs and report measured efficiency and quality dispositions.
- One exact-member archive: loader, companion Wasm, core metadata, concise host contract, source/version identity and required notices.
- Run the existing offline lifecycle and independent native parity checks against the extracted archive itself, with missing/mismatched/tampered-content controls.
- Extend the existing exact release join, checksum, attestation, prohibited-content scan and download/rehearsal contracts while preserving all 18 native archives.
- Audit pinned generated-runtime distribution rights and document integration limits.

## Alternatives and triggers

Measured accuracy is valuable but has no current evidenced title-blocking mismatch; promote a specific reproducible gap. Souper/BupChip/YM2151 and broad AI/TAS tools are larger features without a present scoped consumer need. The browser player and new emulator interface remain separate dormant ideas. Previous Playstead/RetroArch evidence is deferred and its host stops remain closed.

The bundle improves availability for integrators; external demand remains unmeasured. It establishes no browser gameplay, device UX, browser performance, power draw or physical hardware accuracy.
