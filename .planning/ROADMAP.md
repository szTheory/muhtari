## Current position

v11.0 completed the measured delivery/maintenance tune-up, reconciled the
Phase 27 register counts without changing verdicts, and shipped explicit
Windows drive and extended UNC path support throughout `muhtari-run`. Windows
x64 and ARM64 acceptance passed; stable v0.18.0 is published, with exact-source
main CI, Release and latest-install checks green. See the [v11.0 audit](milestones/v11.0-MILESTONE-AUDIT.md).

No next milestone is selected. The [rolling product roadmap](PRODUCT-ROADMAP.md)
contains the current recommendation, strongest alternative and evidence needed
before a scope choice.
