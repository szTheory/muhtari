  <behavior>
    - headers: one 4-byte header with width 1 costs T0 + 9 + 8 + 3; one 5-byte header with width 1 costs T0 + 9 + 10 + 3
    - widths: width 1, 8 and 32 (5-byte W = 0 means 32) cost 3 ticks per graphics byte
    - indirect: a 1-byte indirect object costs 6 per character, a 2-byte (CTRL character width) 9 per character
    - holes: an object whose graphics address falls in a hole (holey 8 or 16 per CTRL) costs header + 3 when direct and 6/9 when indirect, and writes nothing to line RAM
    - terminators: byte 1 in {$00, $20, $40, $80, $A0, $C0} with byte 1 & $1F = 0 ends the DL when `(v & 0x5F) == 0`, so $40, $60, $C0, $E0 with bit 6 set read as 5-byte headers
    - last line: the same DL costs 6 more ticks on a zone's last line, and the next DLL entry is read there
    - abort: a DL whose fetches run past LRC stops at the first fetch whose address tick is at or after LRC; HALTRST = LRC + 3 (ordinary) or LRC + 9 (last line); stats flag ABORTED; objects counts only finished objects
    - line_ram: the bytes written for 160A, 160B, 320A, 320B, 320C and 320D (read mode 2) objects match A7800-MARIA section 3's mapping, and kangaroo mode changes only what section 3 says it changes
    - stats: cost, bytes, headers and objects equal the closed form's terms for a mixed DL
    - feature_mask: each feature bit sets on the first line that uses it and stays set
  </behavior>
