## Artifacts this phase produces

All new names are proposed: internal `struct muhtari__savekey` and instance member `savekey`; fields `host_scl, host_sda, sda_low, phase, bits, shift, address, address_high, read_byte, page[64], touched[64], page_base, page_offset, pending, busy_until`. Use fixed-width types and one page only. Internal functions `muhtari__savekey_pins(m, tick)`, `muhtari__savekey_catch_up(m, tick)`, `muhtari__savekey_reset(m)` live in the current `ports.c` device owner and are declared in `internal.h`. New named constant `MUHTARI__SAVEKEY_BUSY_TICKS=35796` represents ceil(315000000/8800) half-crystal ticks, the selected NTSC 5 ms maximum model. The changed RIOT write contract takes the data tick explicitly. New test cases: `input.savekey.pins/protocol/wrap/recovery`, `core.battery.deadline/no_poll/reset`. No new package, flat EEPROM CPU descriptor, speech surface or layout version is introduced.
