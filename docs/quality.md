# Quality evidence

The root `quality.json` owns ordinary integer floors, ceilings and bounded dated reasons.
Native, hygiene and ASan observations come from completed, inventory-checked JUnit;
archive sizes come from the three validated zip files. Native counts cover ABI,
fuzz replay and public compatibility title predicates, including their controls.
Zero findings require the actual ABI, fatal-warning, analyzer or sanitizer judge.
Each observation identifies its built SHA, configuration, producer and source run.

Initial ordinary bounds use an independently built, unchanged event-base tree on
the same runner with matching compiler and fixture comparison identities. Native bounds
apply to every native leg; the archive ceiling covers the largest three-archive
total across the six native legs. This bounds package size across the platform set;
it does not measure each platform's percentage growth. The ceiling remains 399937
bytes; native test floors remain 605 and 593. Adoption cannot reset an existing bound or initialize another metric from its own
candidate measurements. Ordinary bounds ratchet against the trusted base policy.
Compressed archive bytes vary slightly when rebuilding unchanged inputs. Initial
adoption uses the minimum actual independent-base peak observed in the comparable
cohort; it grants no extra bytes for that variation. This remains a strict ceiling
on actual output, alongside the independent archive contents and firmware judges.
An exact reason names the metric, old/new bound, rationale, grant and expiry dates;
its lifetime is at most 60 days. Inherited expiry and renewal are checked every run.

Fixture comparison permits a narrow additive relation: only unique new rows for
`tests/diag/activision.a78`, `tests/diag/absolute.a78` and
`tests/diag/fractalus.a78` may be added. Each has exactly six tab-separated fields:
the named path, `this-repo`, a nonempty pin without whitespace, `MIT`, a 64-digit
lowercase SHA-256 and `-`. All old rows and other manifest text remain byte-identical
and in order. Changed, deleted or duplicate old paths, duplicate additions,
unrelated paths, malformed fields and added comments fail. A later base containing
any named board row protects it as an old row; that row cannot be edited or repeated.

The producer obtains trusted manifest bytes directly from the independently resolved
event-base Git commit, alongside the original base-policy and SHA authority. PRs use
the event's base SHA, pushes use `before`, and dispatches use the event head's first
parent. After proving the relation, both current and rebuilt-base observations use
the original trusted manifest's SHA-256 as their shared comparison identity. The
recursive invocation uses the current evidence script and independently reads that
same event and Git object. There is no candidate-provided shared digest or ignored
identity field. Local observation production without an event retains the raw
manifest digest and provides no independent-base acceptance.

Compiler identity/version, platform/architecture and the complete built-sample
expectation digest remain unchanged components of the environment. The producer
and join still require exact complete environment equality; every individual lane
must validate before reduction. This comparison identity does not admit fixture
bytes, validate licensing, prove a diagnostic's behavior or replace raw content
hashes. Manifest admission, exact fixture digests, independent rebuilds and hash
coverage retain their separate authority.

The maintenance-line metric and its exclusive counter, inventory and adoption
handling are retired. The trusted-base key-retention check permits only the literal
legacy `gate_lines` key to be absent from candidate policy. Raw base-policy bytes
remain unchanged and independently authenticated; every other base key must remain.
A newly introduced metric still needs ordinary independently measured baseline
evidence. This transition adds no generic ignored-key list or closed metric registry;
the current judge does not reject every additional observation key or complete
unknown metric. For changed check architecture and new resource bounds, follow
ENGINEERING §11 in the preparation index.

The required `quality` job downloads the exact six native, hygiene and ASan artifact
set from its own run. Every lane must supply current/base observations, the event-base
SHA and unchanged base policy. Missing lanes, wrong identities or mismatched
compiler/fixture environments fail. Each individual observation is checked before
reducing to the worst measured value per bound and calling the existing typed judge.
Direct PR runs additionally require the actual test-card Ir artifact.
Pushes and release-called CI report intentionally unexecuted Ir as unavailable.
Planning-only CI skips quality alongside the other heavy work; `CI required` checks
its exact dependency membership and rejects failed, omitted or wrongly skipped quality.

Coverage, open crashes, backlog and comparable historical duration remain explicit
gaps. Library, WASM and property observations remain advisory. Cachegrind evidence
names the test-card workload and retains the existing semantic comparator; its
test-card threshold is armed after the [arming controls](testing.md#performance);
the broader workload remains limited to that fixture.
An absent or unstable base is unavailable, not a passing comparable measurement.
Hash equality, public compatibility, ABI, sanitizers, performance and archive
semantics retain their independent consumers. The aggregate owns ordinary thresholds
and reasons, without replacing those domain judges or promoting advisory lanes.

Performance keeps its comparator and `tests/perf/allow.txt`; compatibility keeps its
ledger judge and `tests/compat/allow.txt`. Each store matches the domain identity and
checks a reviewed expiry within 60 days. Compatibility always requires fresh results
to equal evaluated ledger rows by identity, status and evidence in both directions,
even with an allowance. A live matching allowance can waive loss of a trusted-base
pass. Once merged, that nonpass can become the next base without the original pass
obligation. These legacy stores provide no immutable grants, renewal prevention or
automatic restoration. Their policy remains separate from ordinary aggregate reasons.
