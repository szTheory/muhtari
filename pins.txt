# scripts/fetch-pin.sh NAME DEST downloads a row and verifies its SHA-256 before use.

# Bump policy: take an LTS patch release when it fixes a security advisory, and move
# to the next LTS before this one's end of life. Each bump is one `ci:` pull request
# whose digest comes from the release API (the asset's `digest` field). Packages
# installed with apt stay unpinned: they are signed, and drift fails loudly as a
# build failure or a hash change.
