# any file git treats as binary unless its path is the first field of a line
# here. ASSET_POLICY.md section 2 says which files may be listed.
#
# One line per file, fields separated by a tab:
#
#   path<TAB>source<TAB>pin<TAB>licence<TAB>sha256<TAB>notice
#
#   path     the file's path from the repository root
#   source   where the file comes from (a repository URL, or this-repo)
#   pin      the upstream commit, or a release tag plus asset name
#   licence  the licence that permits redistribution (SPDX expression)
#   sha256   the file's SHA-256, 64 lowercase hex digits
#   notice   the THIRD-PARTY-NOTICES.md section, or -
#
# Lines starting with # are comments.
